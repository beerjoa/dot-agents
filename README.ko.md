## [OpenCode 설정](./opencode/opencode.json)

개인정보를 제거한 `opencode.json`에는 다음 내용이 포함되어 있습니다.

- **플러그인 및 MCP** — 플러그인과 MCP 서버 설정
- **Provider** — `commandcode`와 `opencodex` 설정
- **모델** — 모델 한도 및 런타임 환경설정
- **인증정보** — 민감한 값을 위한 환경변수 참조
