# Optional images

The local Lotus theme contains two desktop backgrounds (`1-kanagawa.jpg` and
`2-stillness.png`), an Omarchy image, previews and an unlock image. Their binary
files are not included in this initial color/source migration.

Add reusable desktop backgrounds here with their original source and license
before distributing them. Keep OS-specific unlock/lock-screen application under
the corresponding platform adapter. Colors, terminal settings and browser themes
do not require these images.
