# Terminal colors

Generated Ghostty, Kitty and Alacritty files contain background, foreground,
selection, cursor and ANSI colors only. Include/import one file into an existing
terminal configuration; do not replace the complete application configuration.

The files can be used independently of the native host, browser extensions and
Omarchy Scheduler. Select the appropriate app and palette on each device.
Ghostty supports native system light/dark switching with the existing two color
files; see the [Ghostty installation and update guide](ghostty/README.md).
Automatic switching for Kitty and Alacritty outside Omarchy is not implemented
here.
