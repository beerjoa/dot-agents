# LazyVim / kanagawa.nvim

The generated `.lazyvim.lua` files are alternative plugin snippets: choose one,
not both. They assume the existing setup uses `rebelot/kanagawa.nvim` and LazyVim.
Only the background override and selected colorscheme are carried over. No
plugin manager, editor bootstrap, machine paths or entire Neovim config is copied.

This is a palette export, not a new universal editor-theme installer.
