설계 명세 경로: $ARGUMENTS

1. `Skill`로 `superpowers:writing-plans`를 호출한다. 인수는 설계 명세 경로 하나로 해석한다. 비어 있으면 대화에서 직전 승인된 설계를 유일하게 식별할 수 있을 때만 사용한다. 경로나 승인 여부가 불명확하면 확인부터 한다.
2. 승인된 설계와 필요한 저장소 파일을 읽고 `docs/superpowers/plans/`에 구현 계획을 작성한다. 스킬 형식을 따라 파일별 범위, Task 인터페이스, 검증 명령과 기대 결과를 명시하고 설계 기준으로 자체 검토한다. 계획만 작성하고 구현은 시작하지 않는다.
3. `git-commit-from-instructions`의 `agent-only` 절차로 계획 파일만 커밋한다. 사용자 변경을 포함하거나 기본 브랜치에 직접 커밋하지 않는다. 커밋이 불가능하면 이유를 보고하고, push하지 않는다.
4. 계획 경로와 커밋을 보고하고, 구현을 시작하기 전에 계획 확인을 요청한다. 확인 후 `/start-build <계획 경로>` 또는 `/start-build-native <계획 경로>`로 이어갈 수 있다.
